# Playtime

Playtime is a Forge 1.20.1 server progression mod that tracks active playtime, ranks, rewards, AFK state, and optional LuckPerms and Open Parties and Claims integration.

## Development

Use Java 17 and the checked in Gradle Wrapper.

```powershell
.\gradlew.bat build
```

```bash
./gradlew build
```

See [the documentation index](docs/README.md) for architecture and verification details.
